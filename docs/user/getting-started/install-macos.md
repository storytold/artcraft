Download the one macOS file from [getartcraft.com/download](https://getartcraft.com/download). It runs on both Apple Silicon and Intel Macs and needs macOS 12.0 or newer.

## What you need

- macOS 12.0 (Monterey) or newer
- 8 GB of RAM recommended
- 2 GB of free storage

## Apple Silicon or Intel

You do not have to choose. The macOS download is a universal build, named like `ArtCraft_<version>_universal.dmg`. It contains both versions.

## Install

1. Open [getartcraft.com/download](https://getartcraft.com/download).
2. Click **Download for Mac**.
3. Open the downloaded `.dmg` file.
4. Install ArtCraft from the window that opens.
5. Start ArtCraft.
6. Create an account or log in. See [Create an account and log in](sign-up-and-log-in.md).

You can also get the file from the [GitHub releases page](https://github.com/storytold/artcraft/releases).

## macOS security prompt

You should not see a warning. The macOS publish workflow signs the build with a Developer ID certificate.

If macOS still blocks ArtCraft, and you downloaded it from getartcraft.com or the GitHub releases page:

1. Try to open ArtCraft once.
2. Open **System Settings**, then **Privacy & Security**.
3. Scroll down and click **Open Anyway** next to the message about ArtCraft.
4. Click **Open** when the warning appears again.

These steps are from Apple's page [Safely open apps on your Mac](https://support.apple.com/en-us/102445). If it still does not open, ask in [Discord](https://discord.gg/artcraft).

## macOS 12 (Monterey)

Sign-up used to freeze on Monterey (issue [#1008](https://github.com/storytold/artcraft/issues/1008)). A fix was merged and the issue is closed.

## Update

ArtCraft has no built-in updater. To get a newer version, download the latest file from [getartcraft.com/download](https://getartcraft.com/download) and install it again.
