Download the installer from [getartcraft.com/download](https://getartcraft.com/download) and run it. ArtCraft for Windows is a 64-bit app.

## What you need

- Windows 10 (64-bit) or newer
- 8 GB of RAM recommended
- 2 GB of free storage

## Install

1. Open [getartcraft.com/download](https://getartcraft.com/download).
2. Click **Download for Windows**. This downloads a file named like `ArtCraft_<version>_x64-setup.exe`.
3. Open the downloaded file and follow the installer.
4. Start ArtCraft.
5. Create an account or log in. See [Create an account and log in](sign-up-and-log-in.md).

You can also get the installer from the [GitHub releases page](https://github.com/storytold/artcraft/releases). Each release lists a `x64-setup.exe` installer and an `.msi` installer. The download page links the `x64-setup.exe` one.

## Windows security prompt

Windows can show a warning when you run a downloaded installer. This page does not cover that prompt yet, because it has not been checked against a release. If you are unsure, download only from getartcraft.com or the GitHub releases page above and ask in [Discord](https://discord.gg/artcraft).

## Where it installs

This page does not say where ArtCraft installs, because that has not been checked yet.

## Update

ArtCraft has no built-in updater in version 0.42.0. To get a newer version, download the latest installer from [getartcraft.com/download](https://getartcraft.com/download) and run it. The download page shows which version it offers.

Ask in [Discord](https://discord.gg/artcraft) or open an issue in the [issue tracker](https://github.com/storytold/artcraft/issues).
