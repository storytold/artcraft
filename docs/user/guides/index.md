Each guide covers one task. Pick the one that matches what you want to do.

## Make and edit images

- [Make an image from a prompt](text-to-image.md): write a prompt in **Create Image** and generate.
- [Edit an image with a prompt](edit-an-image.md): load an image, describe the change, generate.
- [Compose on the 2D canvas](2d-canvas.md): the tools in **Image Editor**.

## Make video

- [Turn an image into a video](image-to-video.md): start from an image in **Create Video**.

## Work in 3D

- [Stage a scene in 3D](3d-editor.md): place objects and a camera in **3D Stage**, then generate from the frame.
- [Turn an image into a 3D object](image-to-3d.md): generate a 3D model from one image.

## Manage your work

- [Find, download and delete your creations](library.md): open **My Library**, download files and delete them.

## Before you start

- You need an account. See [Sign up and log in](../getting-started/sign-up-and-log-in.md).
- Generations cost credits. See [Credits and pricing](../getting-started/credits-and-pricing.md).
- Models differ in the settings they offer. See [Models](../reference/models.md).
